# Ethics and Synthetic Data Statement — mEd EMR

## Statement of data use

**All data used in the development, testing, and demonstration of the mEd EMR system is entirely synthetic (fabricated). No real patient data, real patient identifiers, or any real personal health information has been used at any stage of this project.**

Specifically:
- The demo patients (Yaw Mensah, Akosua Owusu, Emmanuel Boateng, Abena Asante, Kwame Darko) are fictional persons with fictional names, dates of birth, national IDs, and clinical records. They do not correspond to any real individual.
- The demo hospitals (UGMC, KATH, Trust Hospital) are real Ghanaian facility names used to provide authentic clinical context in the demo narrative, but all staff accounts, patient records, encounters, diagnoses, prescriptions, lab results, and allergy records associated with them in the system are entirely fabricated.
- The demo staff usernames correspond to fictional individuals, not to real employees of any of the named hospitals.
- National IDs follow the pattern `GHA-001-001` through `GHA-001-005` — an obviously non-real, sequential format.
- Phone numbers follow the pattern `+233244001001` through `+233244001005` — sequential and non-operational.
- All demo data is generated by the `seed_demo` management command (`core/management/commands/seed_demo.py`), which contains only hardcoded, clearly synthetic values.

## Ethics posture

This project was developed as an academic submission for a university computing programme. As such:
- **No ethics approval was required** because no real human subjects were involved and no real personal data was processed.
- **No real clinical scenarios were reproduced**. Clinical content (diagnoses, prescriptions, lab values) is illustrative and should not be interpreted as medical advice.
- The system architecture is designed to support a real deployment under appropriate governance (see `docs/adr/009-consent-legal-basis.md` for the legal-basis analysis), but no such deployment has been made.

## Git history check

Before submission, the following checks were performed to confirm no real data entered version control:
- `git log --all --grep "patient" -p` — no real names or IDs found.
- `.env` files are listed in `.gitignore` and excluded from the repository; the repository contains only `.env.example` with placeholder values.
- The `seed_demo.py` file contains only the synthetic values listed above.

## Commitment going forward

Any future real deployment of mEd would require:
1. Institutional ethics approval from the relevant review board.
2. Formal consent from participating hospitals and patients.
3. A Data Protection Impact Assessment (DPIA) under the Ghana Data Protection Act, 2012.
4. Engagement with the Data Protection Commission of Ghana.
